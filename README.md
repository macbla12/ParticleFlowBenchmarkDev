# Particle Flow Bencharmking & Tuning Development

This is a development repo intended to consolidate code related to particle flow (PF) benchmarking and tuning. Code will eventually be migrated to [`detector_benchmarks`](https://github.com/eic/detector_benchmarks) and [`physics_benchmarks`](https://github.com/eic/physics_benchmarks) as needed.

When committing changes, please push code directly to main (no PRs required). Standard etiquette when working on a shared repo applies:

- Don't forget to pull (`git pull origin main`) before pushing, and
- Please don't edit others' code without communicating!
